## Projeto de Teoria dos Grafos: Implementação e Análise de Árvores

<p>
Este projeto consiste na implementação e análise comparativa de estruturas de dados avançadas para busca e balanceamento, focando especificamente em **Árvores Rubro-Negras** e sua relação isomórfica com as **Árvores 2-3-4**.</p>

### 📌 Sobre o Projeto

O objetivo principal é demonstrar como o balanceamento de árvores de busca binária pode ser otimizado através de regras de coloração e rotação, garantindo complexidade de tempo de $O(\log n)$ para operações de inserção, remoção e busca.

### Conteúdo Implementado:
- **Árvores 2-3-4**: Uma árvore de busca multi-caminho equilibrada.
- **Árvores Rubro-Negras**: Implementação binária eficiente que mantém o equilíbrio através de propriedades de cores (Vermelho/Preto).
- **Algoritmos de Rotação**: Simples (esquerda/direita) para manutenção do balanceamento.
